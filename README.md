# Angielska Przygoda

Prosta gra edukacyjna do nauki angielskich słówek przez dopasowywanie obrazków i wyrazów.

## Uruchomienie

Projekt jest statyczną stroną internetową. Otwórz `index.html` w przeglądarce albo uruchom dowolny lokalny serwer HTTP.

Repozytorium jest przygotowane do bezpośredniego wdrożenia w Vercel bez etapu budowania.
